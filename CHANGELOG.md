# Changelog

All notable changes to this project will be documented in this file.

## [v0.1.0] - Initial Setup
- Initialized Next.js project.
- Set up Prisma database schema.
- Added global styles, theming and animations.
- Configured icons and basic components.

## [v0.2.0] - Authentication and User Profiles
- Implemented user login and registration system.
- Added user profile pages.
- Configured user sessions.
- Added a password reset flow.

## [v0.3.0] - Core Tracking Features
- Added Movie detail pages (`/movie/[id]`).
- Added TV Show and Episode pages (`/tv/[id]`, `/tv/[id]/season/...`).
- Created a robust search functionality.
- Implemented "Trending" and discovery features.
- Implemented user collections to group movies/shows.

## [v0.4.0] - Social & Personalization
- Added "Wrapped" feature for end-of-year review.
- Added Achievements tracking.
- Created Cast and Crew (Person) pages.
- Configured a comprehensive user settings page.
- Various UI tweaks, responsive fixes, and polish.

## [v0.4.1] - UI Improvements
- Enhanced visibility and styling of the 'Back' buttons across Movie, TV Show, Episode, and Collection pages for better navigation.
